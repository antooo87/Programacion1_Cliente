# Ejercicio 01 — Hola consola

## Enunciado

Abre la consola del navegador (F12 → pestaña "Console") y escribe en `app.js` el código necesario para que, al cargar la página, aparezca en la consola el mensaje:

```
Hola, mundo
```

Después, añade un segundo mensaje con tu propio nombre, por ejemplo:

```
Hola, soy <tu nombre>
```

## Pistas

- El método para escribir en la consola es `console.log(...)`.
- Recuerda que `app.js` se carga con `defer`, así que no necesitas esperar a ningún evento para que tu código se ejecute.
