# Ejercicio 02 — Tipos y typeof

## Enunciado

Declara al menos 6 variables, una por cada uno de estos tipos: número, string, booleano, `undefined`, `null` y un array u objeto.

Para cada una, escribe en consola una línea con este formato:

```
<nombre de la variable> es de tipo <resultado de typeof>
```

Al final, responde (en un comentario en el propio `app.js`, encima de la línea correspondiente) a esta pregunta: ¿qué devuelve `typeof null`? ¿Te parece lo que esperabas?

## Pistas

- `typeof variable` devuelve un string con el tipo, por ejemplo `"number"` o `"string"`.
- Puedes usar un template literal para construir el mensaje: `` `${nombreVariable} es de tipo ${typeof variable}` ``.
