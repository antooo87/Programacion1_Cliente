# Ejercicio 03 — Par o impar

## Enunciado

Escribe una función `esPar(numero)` que reciba un número y devuelva `true` si es par y `false` si es impar.

Pruébala en consola con al menos 4 números distintos (dos pares y dos impares, incluyendo el `0` y algún número negativo), mostrando el resultado con `console.log`.

## Pistas

- El operador módulo `%` devuelve el resto de una división. Un número es par si el resto de dividirlo entre 2 es `0`.
- Usa `===` para comparar el resto con `0`, no `==`.
