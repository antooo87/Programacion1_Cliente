# sandbox

Carpeta de pruebas rápidas de clase: experimentos, trozos de código para probar un concepto suelto, cosas que se siguen en directo en una sesión.

- No se entrega en la Arena.
- No tiene estructura fija ni normas de estilo estrictas.
- Se puede borrar y recrear sin avisar a nadie.
- Si algo de aquí acaba siendo útil de verdad, se traslada (limpio) a `ejemplos/` de la unidad que corresponda.
